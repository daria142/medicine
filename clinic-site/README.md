# Сайт частной клиники

Статический прототип: синяя тема, запись в 3 шага, прелоадер, 404.

## Страницы

- `index.html` — главная
- `404.html` — ошибка
- `pages/services.html` — каталог направлений
- `pages/kardiologiya.html`
- `pages/nevrologiya.html`
- `pages/ozonoterapiya.html`
- `pages/plazmoterapiya-prp.html`
- `pages/endokrinologiya.html`
- `pages/onkologiya.html`
- `pages/prices.html` — поиск и фильтры прайса
- `pages/doctors.html` и `pages/doctor.html`
- `pages/checkups.html`
- `pages/patients.html`
- `pages/about.html`
- `pages/contacts.html`
- `css/styles.css`, `js/main.js`

Откройте `index.html` в браузере. Данные клиники правятся на странице `pages/admin.html` (ссылка «Данные сайта» в подвале главной).

Локальная кнопка меняет текст только в этом браузере. Чтобы обновление увидели все посетители, скачайте `site-data.js` и замените файл `js/site-data.js` перед загрузкой на хостинг.
